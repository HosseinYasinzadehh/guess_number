# 🎯 Guess the Number

A simple number guessing game built with Python.

The computer chooses a random number between 1 and 100, and the player tries to guess it within 7 valid attempts.

## ✨ Features

- Random number generation between 1 and 100
- User input validation
- Feedback for each guess
- Maximum of 7 valid attempts
- Replay option
- Handles invalid inputs without crashing
- Organized using Python functions

## ▶️ How to Run

Make sure Python is installed on your computer.

Clone the repository:

    git clone https://github.com/HosseinYasinzadehh/guess_number

Go into the project directory:

    cd guess_number

Run the game:

    python main.py
